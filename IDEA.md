# Krish Creative Studio Pro

Krish Creative Studio Pro is a modern AI-powered Creative Design Studio focused on creating high-converting digital marketing creatives.

Version 1 focuses on a Meta Ads Generator that enables users to create professional Facebook and Instagram advertisements using editable templates, visual canvas editing, image uploads, branding tools, and high-resolution exports.

Future versions will expand into a complete Creative Studio supporting:
- Facebook
- Instagram
- WhatsApp
- LinkedIn
- X (Twitter)
- Pinterest
- Google Display Ads
- YouTube

Tech Stack:
- React
- Vite
- TypeScript
- Tailwind CSS
- Zustand
- Framer Motion
- Lucide React
- html-to-image
- Vercel

UI Style:
- Glassmorphism
- Neon Glow
- Dark Mode
- Premium SaaS Dashboard
- Responsive
- Modern Enterprise Design

Development Rules:
- Build one milestone at a time.
- Never generate the entire application in one step.
- Explain the implementation plan before writing code.
- Generate only the files required for the current milestone.
- Wait for user approval before proceeding to the next milestone.
- Write clean, modular, reusable, production-ready TypeScript code.
- Keep the architecture scalable for future modules.

Current Goal:
Complete Phase 1 by creating the project foundation, folder structure, routing, dashboard shell, responsive sidebar, top navigation, placeholder pages, and a working development environment without implementing business logic.
